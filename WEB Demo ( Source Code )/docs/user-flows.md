# Luồng demo

1. Đăng ký Người chơi/Chủ sân → mã số điện thoại 482915 → thông báo thành công ngay trang xác thực → đăng nhập. Chủ sân mới chờ admin duyệt.
2. Admin → Duyệt chủ sân → xem thông tin/sân → duyệt hoặc từ chối có lý do. Chủ sân bị từ chối có thể cập nhật/gửi lại.
3. Chủ sân → Quản lý sân → đề xuất thêm/sửa/xóa → Admin-Dashboard, nhóm sân → duyệt → thay đổi có hiệu lực. Sau đó mở khung giờ từ Quản lý đặt sân.
4. Người chơi → Tìm sân → chi tiết → chọn giờ → đồng ý chia sẻ liên hệ → gửi → hoạt động. Chủ sân → yêu cầu mới → duyệt. Sau thời gian thuê, chủ sân hoàn thành → người thuê đánh giá.
5. Người chơi → Tạo trận trên lịch đã duyệt. Tài khoản khác → yêu cầu tham gia. Chủ trận → Join-Requests → xem thống kê → chấp nhận/từ chối.
6. Người chơi → Ghép trận theo trình độ → nhập tiêu chí → gợi ý có giải thích → lưu hoặc xem chi tiết → gửi yêu cầu.
7. Bấm tên người chơi / báo cáo sân → Report → nội dung và bằng chứng → admin xử lý → người dùng nhận thông báo.
8. Admin → Gửi thông báo → chọn nhóm → gửi; có thể thu hồi. Chat → chọn người nhận → gửi; đổi tài khoản trong cùng trình duyệt để đọc.
9. Hồ sơ → Đổi mật khẩu → xác thực số điện thoại → mật khẩu mới → đăng nhập lại. Không mở thẳng bước cuối để bỏ xác thực.
