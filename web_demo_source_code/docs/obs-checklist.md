# Checklist OBS theo từng màn hình

Số video căn cứ bảng kiểm kê cuối cùng đã được giảng viên duyệt. Bản triển khai hiện có 40 tệp HTML; không có nghĩa thầy đã duyệt 40 giao diện. Nhóm cần chốt cách tính trang auth, trạng thái và modal.

Mỗi video cần:
- [ ] Có mặt sinh viên phụ trách.
- [ ] Mở bản Figma/Canva tương ứng và nói mục tiêu người dùng.
- [ ] Mở đúng HTML, module JS và phần CSS liên quan.
- [ ] Giải thích dữ liệu, validation và trạng thái.
- [ ] Chỉnh một chi tiết có ý nghĩa trực tiếp.
- [ ] Chạy lại tương tác, kiểm tra mobile khi phù hợp.
- [ ] Commit trên nhánh của task, nêu task/nhánh/commit.
- [ ] Gắn PR/review và video vào task-board.csv hoặc bảng Trello thật.

Tên đề xuất: SV1-01-player-court-search.mp4. Không quay demo thuần rồi coi như đã đủ yêu cầu. Không dùng script để tạo bằng chứng làm việc giả.

Bài tập bảo vệ 5–10 phút: thêm bộ lọc môn/ngày, thêm field và validation, thay table bằng card ở mobile, xử lý dữ liệu rỗng, thêm trạng thái có chuyển tiếp rõ ràng.
