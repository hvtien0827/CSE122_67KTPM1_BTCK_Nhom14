# Danh mục chính xác 28 trang

Không giữ trang chuyển hướng cũ. Các phần chi tiết/thành công dùng trạng thái hoặc tham số trong trang hiện hành.

| STT | File | Giao diện |
|---|---|---|
| 1 | `index.html` | Trang chủ |
| 2 | `login.html` | Đăng nhập |
| 3 | `register.html` | Đăng ký |
| 4 | `forgot-password.html` | Quên mật khẩu |
| 5 | `reset-password.html` | Đặt lại mật khẩu |
| 6 | `verify-email.html` | Xác thực số điện thoại |
| 7 | `verify-reset.html` | Xác thực đổi mật khẩu |
| 8 | `help.html` | Trợ giúp |
| 9 | `chat.html` | Trò chuyện |
| 10 | `notifications.html` | Thông báo |
| 11 | `profile.html` | Hồ sơ cá nhân |
| 12 | `settings.html` | Cài đặt |
| 13 | `privacy.html` | Quyền riêng tư và điều khoản |
| 14 | `error.html` | Thông báo lỗi |
| 15 | `Report.html` | Báo cáo |
| 16 | `my-activities.html` | Hoạt động của tôi |
| 17 | `player-court-search.html` | Tìm kiếm sân |
| 18 | `player-open-matches.html` | Các trận đấu đang mở |
| 19 | `player-match-create.html` | Tạo trận đấu |
| 20 | `player-skill-match.html` | Tìm trận theo trình độ |
| 21 | `Join-Requests.html` | Yêu cầu tham gia trận |
| 22 | `venue-booking-management.html` | Quản lý đặt sân |
| 23 | `venue-court-management.html` | Quản lý sân |
| 24 | `Revenue.html` | Thống kê doanh thu |
| 25 | `Admin-Dashboard.html` | Quản lý tổng |
| 26 | `Court-Owner-Approval.html` | Duyệt chủ sân |
| 27 | `Report-Management.html` | Quản lý báo cáo |
| 28 | `System-Notifications.html` | Gửi thông báo |

`player-court-search.html?id=...` xem sân; `?slot=...` xác nhận đặt. `player-open-matches.html?id=...` xem trận. `Admin-Dashboard.html?tab=courts` mở quản lý sân. `Report.html?type=user&id=...` hoặc `type=court` mở báo cáo theo ngữ cảnh.
