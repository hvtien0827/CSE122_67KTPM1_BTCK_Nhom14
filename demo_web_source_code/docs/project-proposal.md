# Đề xuất hiện hành CourtConnect

Website đặt sân và kết nối người chơi, phục vụ nhóm 4 sinh viên. Bản triển khai hiện hành có 28 HTML và 3 vai trò theo tài liệu phân loại giao diện mới. HTML/CSS/JS thuần, lưu dữ liệu cục bộ, không dùng backend.

Mục tiêu: đi hết luồng tài khoản, phê duyệt chủ sân/sân, đặt sân, tổ chức/tham gia trận, đánh giá sân và xử lý báo cáo; hỗ trợ gợi ý theo trình độ và cảnh báo lịch hủy bằng quy tắc.

Giới hạn, danh sách trang và kế hoạch kiểm thử nằm trong README, screen-list.md và test-report.md. Nhóm cần xác nhận lại thay đổi phạm vi với giảng viên nếu đề gốc yêu cầu những phần đã bỏ; mã hoàn thành không thay thế phê duyệt học phần.
